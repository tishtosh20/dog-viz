# WHO'S A GOOD NAME? 🐶

**Who's a Good Name?** is an interactive data visualization exploring the most popular dog names in NYC. Inspired by my two huskies, Sven and Blue, I wanted to turn a simple dataset into something more playful.

The website features a guessing game where users match the five most popular dog names to their corresponding bars, followed by a polar area chart displaying the top 20 names.

### Design Process

I started by downloading the [NYC Dog Licensing Dataset](https://data.cityofnewyork.us/Health/NYC-Dog-Licensing-Dataset/nu7n-tubp) and using JavaScript to convert the CSV into JSON, counting and sorting the most common dog names.

Initially, I experimented with a polar area chart, but I felt that simply displaying the data wasn't interactive enough. I decided to introduce a guessing game using a bar chart, allowing users to engage with the data before exploring the full top 20.

I also experimented with different color palettes before settling on yellow and blue, inspired by the colors dogs can distinguish most easily. I used the Modak font to give the website a playful, almost childlike appearance.

### Tools

HTML, CSS, JavaScript, Chart.js, Node.js, and csv-parse.

### AI Usage

I used ChatGPT to help develop the guessing game's mechanics, write and refine CSS styling, troubleshoot errors, and better understand parts of my JavaScript code.
